# 1 Dia – Um dia de cada vez

App gratuito de apoio diário na recuperação: contador de tempo limpo, marcos de 1 dia até 50 anos com chaveiros coloridos, inventário diário, motivos, companheiros, reuniões e ajuda a um toque.

**Acesse:** https://ljradar.github.io/um-dia/

- Sem cadastro: os dados ficam só no celular de cada pessoa.
- Pode ser instalado na tela inicial (iPhone: Compartilhar → Adicionar à Tela de Início; Android: ⋮ → Instalar app).

App independente, sem vínculo com Narcóticos Anônimos ou outra irmandade. Não substitui tratamento médico ou psicológico.
